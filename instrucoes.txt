O FURGfs4 é um pequeno sistema de arquivos que reside inteiramente dentro de um outro arquivo a ser armazenado em um sistema de arquivos real. Ele usa conceitos vistos em aula como FAT (tabela de alocação de arquivos) e operações sobre arquivos e diretórios. O FURGfs4 suporta diretórios e um número finito (e > 100) de arquivos. Sua tarefa é criar um programa que implementa o FURGfs4.
As operações suportadas são:
1. criar um FURGfs4 no tamanho escolhido pelo usuário (você pode delimitar opções tamanhos mínimos e máximos, desde que mínimo 6= máximo)
• está opção resultará na criação de um novo arquivo no sistema de arquivos real (e.g., trabalhos/SO/furgfs3.fs)
• este novo arquivo terá o tamanho escolhido para o FURGfs4
• i.e., se o usuário escolheu criar um sistema de arquivos de 800MB, o arquivo furgfs3.fs terá 800MB.
2. copiar um arquivo de um sistema de arquivos real (disco, pendrive, etc) para dentro do FURGfs4 (cp <origem>/arquivo <furgfs>/arquivo)
3. copiar um arquivo de dentro do FURGfs4 para um sistema de arquivos real (disco, pendrive, etc) (cp <furgfs>/arquivo <destino>/arquivo)
4. renomear um arquivo armazenado no FURGfs4 (mv antigo.txt novo.txt)
5. remover um arquivo armazenado no FURGfs4 (rm arquivo.mp3)
• rm -r é extra
6. listar os arquivos/diretórios armazenados no FURGfs4 (ls)
• mostrar tamanho real do arquivo e tamanho ocupado no FURGfs4
7. listar o espaço livre em relação ao total do FURGfs4 (df)
• e.g., 301MB livres de 800MB
8. proteger/desproteger arquivos de escrita/remoção (protect)
9. modo debug para listar o índice dos blocos físicos que compõe o arquivo (debugarquivo.pdf)

• alguns parâmetros devem ser decididos na implementação:
• tamanho do bloco
• tamanho máximo do nome dos arquivos
• ordem que as partes internas são armazenadas (com exceção do cabeçalho)
• metadados (obrigatório apenas nome e tamanho do arquivo)
• o tamanho do sistema de arquivos é de escolha do usuário mas não pode ser muito pequeno a ponto de o sistema de arquivos não ser utilizável
• os primeiros bytes devem conter um cabeçalho contendo informações necessárias para encontrar o restante das informações
• tamanho do cabeçalho
• tamanho do bloco
• tamanho do sistema de arquivos
• endereço de início da FAT
• endereço de início do diretório raiz
• endereço de início dos dados
